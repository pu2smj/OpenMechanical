# AGENTS.md

## Project Overview

OpenMechanical is an open-source FreeCAD workbench containing parametric mechanical component libraries. It generates 3D models from verified engineering data (ISO/DIN/ANSI standards, manufacturer catalogs).

**Engineering First**: Geometry is generated from parameters, not the other way around.
Every dimension must have a documented technical source.

This project evolved from OpenBearingWorkbench (deep groove bearings) into a multi-library workbench. The design principles are documented in `ENGINEERING_PRINCIPLES.md` and `MANIFESTO.md` — read them before contributing.

## Translation System

OpenMechanical uses Qt's `.ts`/`.qm` translation system (standard for FreeCAD workbenches).

### How it works

- `Resources/translations/OpenMechanical.ts` — master template with all extractable strings
- `Resources/translations/OpenMechanical_<locale>.ts` — per-locale translation files
- `Resources/translations/OpenMechanical_<locale>.qm` — compiled binary (generated by `lrelease`)

### Workflow

1. Extract strings: `python Resources/translations/compile_translations.py` (runs `lupdate`)
2. Translate: open `.ts` files in Qt Linguist
3. Compile: `lrelease OpenMechanical_<locale>.ts` → generates `.qm`
4. At runtime, `load_translations()` in `OpenMechanicalWorkbench.py` auto-loads the `.qm` matching the system locale

### Supported locales

See `compile_translations.py` → `supported_locales` dict for the full list.

### Adding a new language

1. Copy `OpenMechanical.ts` → `OpenMechanical_<locale>.ts`
2. Translate all `<source>` strings in the `.ts` file
3. Compile to `.qm`
4. Place `.qm` in `Resources/translations/`

### Crowdin (Optional)

For collaborative translation, Crowdin is supported via `crowdin.yml`:
1. Push strings to Crowdin: `crowdin upload sources`
2. Translate on the Crowdin platform
3. Download translations: `crowdin download`

## State of the Libraries

- **BearingWorkbench**: the only fully parametric, data-driven library. Deep groove bearings, ISO 15 data, shields (Z/ZZ) and seals (RS/2RS).
- **ORingWorkbench**: parametric, data-driven from 4 normalized CSVs (`o-ring_pol.csv` AS568 in inch+mm, `o-ring_mm.csv` metric, `brand.csv` manufacturer references, `material.csv` materials). O-rings are generated as torus geometry. Key = `fabricante|codigo` (rows without code use `fabricante|metrico|di|w`, e.g. `Smierveda|metrico|1.0|1.0`). Classification rule: 4-digit codes starting with `2` = AS568 (dash = code - 2000); everything else (3xxx, 6xxx, special `2-xxx`/`6-xxx`, code-less metric) = metric. CSVs use semicolon delimiter and comma decimals.
- **Bushing / Coupling / Seal**: these have **placeholder geometry hardcoded** in `OpenMechanicalWorkbench.py` (`make_bushing()`, `make_coupling()`, `make_seal()`). They violate the parametric principle and are placeholders pending data-driven implementations.

## Code Conventions

- **Language**: Python 3, FreeCAD >= 0.19 (supports FreeCAD 1.x)
- **Comments and docs**: Portuguese (project convention, despite English AGENTS.md)
- **Code identifiers**: English
- **Data Source**: All dimensions in `*.json`/`*.csv` must reference ISO/DIN/ANSI standards or a manufacturer catalog
- **Parametric**: Never hardcode dimensions; derive from data files
- **Modular**: Each file has a single responsibility
- **Documentation**: Technical references required for every dimension

---

## Key Principles

1. Standards before geometry
2. Every dimension must have a documented source
3. Data and geometry remain independent
4. Simplest correct solution preferred
5. Validation before release

## Common Commands

```python
# API Usage (BearingWorkbench)
from BearingWorkbench.main import Bearing
b = Bearing("608ZZ")
print(b.d, b.D, b.ball_diameter)
b.build()

# API Usage (ORingWorkbench)
from ORingWorkbench.main import ORing
ring = ORing("Parker|2001")
print(ring.di, ring.w, ring.de)
ring.build()

# FreeCAD Integration
# Load the "Open Mechanical" workbench in FreeCAD and use the toolbar/menu.
# Bearing command opens BearingSelectionDialog; O-Ring command opens ORingSelectionDialog.
# Bushing/Coupling/Seal use placeholder geometry.
```
